# Cyber Security Notes

## What is Cyber Security?

**Cyber Security** comes from two words:

- **Cyber**: things related to computers and networks
- **Security**: protection

**Cyber security** is the practice of protecting cyber assets from digital or computerized attacks. It has many branches.

## Cyber Attacks

A **cyber attack** aims to access, change, or destroy sensitive information without authorization. Cyber attacks are also known as **hacking**.

**Hacking** is the unauthorized way of gaining access to a system. How?

- **Vulnerabilities**: Finding vulnerabilities, then gaining access based on them in an unauthorized way is known as hacking.

### Ethical Hacking

**Ethical hacking** is hacking with permission — finding vulnerabilities, exploiting the system, and reporting them back to the organization.

> Hackers and ethical hackers need to have the same mindset.

|Type|Description|

|**White Hat**|Helping and good people (us)|
|**Grey Hat**|A mixture of both black hat and white hat activities|

## Why Do Hacks Happen?

**Attack = Motive (goal) + Method + Vulnerability**

**Motives** include:

- Information theft
- Manipulating data
- Financial loss
- Revenge
- Ransom
- Damaging systems

> **Ransom**: Locking a system, then asking for money in exchange for giving back access.

## Elements of Information Security — The CIA Triad

At least **one or more** of these three elements must fail for a system to be considered hacked:

- **C** — Confidentiality
- **I** — Integrity
- **A** — Availability

### Confidentiality

Data is kept secret or private.

_Example_: A banker can see the flow of money and sensitive data. If someone else can view that information from the system without authorization, the system has been hacked and confidentiality has been lost.

### Integrity

Making sure your data is trustworthy and free from tampering or unauthorized change.

_If someone changes data in a system without authorization, integrity has failed._

### Availability

Information should be available to users whenever they need it. If a user cannot access that data when needed, availability has been lost.

## Phases of Hacking

1. **Reconnaissance** — information gathering
2. **Scanning** — vulnerability scanning
3. **Gaining Access**
4. **Maintaining Access**
5. **Clearing Tracks** — removing logs/evidence

## Penetration Testing

**Penetration testing (pentesting)** is the process of evaluating the security of a system.

### Types of Pentesting

|Type|Description|
|---|---|
|**Black Box**|Testing without prior knowledge — you test as an attacker|
|**White Box**|Testing with prior knowledge (e.g., access to source code) — you test as a developer|
|**Grey Box**|Testing with limited knowledge|

## Key Terms

- **Red Teaming**: Simulating real-world attacks to test an organization's security posture
- **Blue Teaming**: Defensive security — defending against attacks and improving security controls
- **Security Audit**: Evaluation of an organization's information system
- **Vulnerability Assessment**: Identifying and classifying security flaws in systems, networks, and software
